# java-swing-loginUI-practice
SignIn and SignUp – Java Swing Login

This project is a modern Java Swing-based login and registration UI designed to showcase clean interface design, smooth animations, and modular component structure using lightweight libraries.

The interface features icon-based input fields (user, lock, email) using SVG and PNG assets to improve clarity and usability. Smooth transitions such as fade-ins and sliding panels are implemented using 

TimingFramework 1.0, providing responsive visual feedback without heavy dependencies.

For layout management, the project uses MigLayout, allowing precise control over spacing, alignment, and resizing to maintain a consistent look across different screen sizes.

The codebase follows a modular design, separating reusable UI components and panels for better maintainability and scalability. While the project currently focuses on UI and interaction design, it can be easily extended with backend authentication logic.

This project is ideal for developers learning Java Swing, MigLayout, and basic animation techniques, and serves as a practical foundation for building real-world desktop applications.
